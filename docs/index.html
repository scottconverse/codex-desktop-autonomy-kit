Codex Desktop Autonomy Kit

A click-first setup kit that configures Codex Desktop for practical local software-development autonomy: persistent instructions, full local development access, toolchain bootstrap, diagnostics, and a bounded elevated helper.

View on GitHub Read the manual

What it does

Configures Codex

Creates or refreshes a kit-managed ~/.codex/config.toml with autonomy-oriented settings and persistent developer instructions.

Installs useful tools

Bootstraps common user-scope development tools: Python, uv, Node.js, GitHub CLI, ripgrep, jq, SQLite, and Playwright.

Handles elevation

Optionally installs a scheduled-task helper so approved development infrastructure actions can run with administrator rights.

Designed for no-CLI operation

Install or update.
Double-click Install-Autonomy.cmd. The installer runs setup, Doctor, and helper refresh checks.
Approve UAC only when needed.
The helper path asks for Windows administrator approval during initial setup or refresh.
Restart Codex Desktop.
After restart, the kit is active through Codex Desktop configuration. There is no special invocation phrase.
Maintain by double-clicking.
Use Doctor, Refresh Helper, Run Tests, or Uninstall from the root launcher files.

Architecture

Safety model

The kit is intentionally powerful because it is for owner-controlled Windows development machines. It preserves custom Codex configs by default, creates backups before overwriting kit-managed configs, and keeps the elevated helper structured around named development actions with logs and result files.

Who it is for

Solo builders

People who want Codex Desktop to finish local setup, builds, tests, and repairs without turning every task into a checklist.

Windows developers

Users who need practical Windows support for services, SDKs, firewall rules, installers, and development tooling.

Kit maintainers

People who want a documented pattern for no-CLI install, diagnostics, uninstall, versioned manifests, and regression tests.
